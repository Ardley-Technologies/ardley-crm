## Known gaps

- **The walkthrough is desktop-only.** Under 768px `CRM.tsx` swaps `DesktopAdmin`
  for `MobileAdmin`, which registers the stock Atomic CRM contact and company
  screens and no `deals` resource at all — only the dashboard is shared. So a
  phone (or any window under 768px, since the breakpoint is live) shows no loan
  triangle, no merge picker and no NMLS search. The graph e2e specs skip
  themselves below that width rather than pretend to cover it.
- Company show has no referred deals, so success criterion 3 is only half met:
  nested agents render, referred deals do not exist on the payload or the page.
- `In Process Loans` has just two stages (`04 - App Started`, `06 - In
  Underwriting`), so "move a loan through numbered stages" is a single hop.
- Two pipelines are both named `Lead - Active` (the W1 one and a roster-generated
  duplicate), one of them with no stages.
- `crm_users.contact_id` is never populated by the login path, so invariant 1
  ("login is a projection of a contact") holds only for seeded users.
- Aurora is **not** re-seeded by a redeploy — the CDK trigger fires only when the
  seed changes. Seed edits need a forced run or direct SQL.
- 6 harness hook tests fail locally (`cleanup-worktree`, `cleanup-session`,
  `setup-worktree`): git worktree creation inside macOS temp paths. Unrelated to
  the app.
